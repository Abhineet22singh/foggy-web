# 🌫️ Foggy Webcam

> **Write on fog — just like a foggy mirror or car window!**

A fun browser app that covers your webcam feed with a realistic fog layer. Draw on it with your mouse or finger to reveal what's behind — exactly like writing on a foggy mirror. The fog slowly creeps back in!

---

## ✨ Features

| Feature | Description |
|---|---|
| 🖐️ **Draw on fog** | Click & drag (or touch) to wipe the fog and reveal the live webcam |
| ⏳ **Auto re-fog** | Cleared areas slowly fog back up on their own |
| 🔘 **Brush Size** | Adjust how big your "finger" is |
| 🌫️ **Fog Density** | Control how thick the fog looks |
| ⏩ **Re-fog Speed** | How fast the fog returns (set to 0 to keep it clear) |
| 🌫 **Re-fog All** | Instantly re-covers the whole screen with fog |
| 📸 **Snapshot** | Download the current foggy frame as a PNG |

## 🚀 How to Run Locally

Just open `index.html` in any modern browser — no installation needed!

```bash
git clone https://github.com/Abhineet22singh/foggy-web.git
cd foggy-web
# open index.html in your browser
```

> ⚠️ Allow camera access when the browser asks.

## 🛠️ Built With

- **HTML5 Canvas API** — per-pixel fog rendering
- **WebRTC / getUserMedia** — live webcam feed
- **Vanilla JavaScript** — zero dependencies
